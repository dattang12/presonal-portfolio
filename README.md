# Dat Tang: Personal Portfolio

My personal portfolio website: about me, resume, projects, hobbies, and how to reach me.

Built with plain HTML, CSS, and JavaScript. No build step and no dependencies to install.

## Features

- About, Resume, Projects, Hobbies, and Contact pages
- Light and dark theme toggle (follows your system setting, remembers your choice)
- Responsive layout for phones, tablets, and desktops

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
